# Neomi Estrada -  Personal Portfolio Website

A responsive personal portfolio website built with HTML, CSS, and JavaScript to showcase my background, experiences, skills, projects, and hobbies.

## Features
- **Responsive Design:** Adapts across desktop monitors, tablets, and mobile devices using CSS media queries.
- **Interactive Navigation:** Includes smooth scrolling and a collapsible hamburger menu for mobile and tablet devices.
- **Interactive Hobbies Gallery:** JavaScript-powered photo switcher with unique captions.
- **Contact Form:** Built-in inquiry form for networking and collaboration.

## Technologies Used
- HTML
- CSS
- JavaScript
